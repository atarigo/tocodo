# 單骰攻擊表

Layer 3 — Rules。本文件定義攻擊表的組表方式與各列的 tag 驅動規則。

## 適用範圍

只有**造成傷害的技能**才進攻擊表。非傷害技能（治癒術、衝刺等）直接跳過攻擊表，效果必定進入生效判定。

## 組表流程

每次攻擊先依攻守雙方數值「組表」，再擲一顆骰決定結果。雙邊數值的比較全部發生在組表時，擲骰本身不看任何屬性。

Bar 依固定優先序填入，空間不足從尾端截斷：普通命中先歸零 → 碾壓被擠出 → 最後才是暴擊。

填入順序（由頭至尾）：閃避 → 躲避 → 招架 → 格檔 → 暴擊 → 碾壓 → 命中（剩餘空間）。

## 各列定義

引擎檢查技能的 tag 與攻擊者的 tag，決定哪些列啟用。不符合條件的列寬度為 0，不佔空間。

### 閃避（Dodge）— 守方 AGI

| 項目 | 內容 |
|---|---|
| 啟用條件 | 技能**沒有** `spell` tag |
| 公式 | `(40% × agi ÷ (agi + 128)) × (1 − 50% × dex ÷ (dex + 128))` |
| 骰中結果 | 無傷害、無效果 |

守方敏捷提供閃避率（飽和曲線，255 AGI ≈ 26.7%），攻方靈巧壓制守方閃避，壓制上限 50%（255 DEX 壓制約 33.2%）。最終閃避率上限約 17.8%。

### 躲避（Evasion）— 守方 LUK

| 項目 | 內容 |
|---|---|
| 啟用條件 | 技能**沒有** `spell` tag |
| 公式 | `12% × luk ÷ (luk + 128)` |
| 骰中結果 | 無傷害、無效果 |

不可被壓縮（incompressible）：無論其他列怎麼膨脹，躲避不會被擠掉。255 LUK ≈ 7.98%。投資極大、上限不到 12%。

### 招架（Parry）— 裝備提供

| 項目 | 內容 |
|---|---|
| 啟用條件 | 技能有 `melee` tag |
| 數值來源 | 武器的 `parryRate`（5%～25%），屬性不提供 |
| 骰中結果 | 傷害 ×0.7（減免 30%），不阻止效果觸發 |

只有近戰攻擊可被招架。遠程（弓、槍）與法術都跳過此列。可被 buff/debuff 修飾。

### 格檔（Block）— 盾牌提供

| 項目 | 內容 |
|---|---|
| 啟用條件 | 無 tag 限制（所有造成傷害的技能皆可被格檔） |
| 數值來源 | 盾牌的 `blockRate`（30%～45%），無盾 = 0，屬性不提供 |
| 骰中結果 | 傷害 ×0.4（減免 60%），可阻止「單體鎖定」效果（但不阻止範圍效果與暈眩） |

盾牌連火球都擋得住。可被 buff/debuff 修飾。

### 暴擊（Crit）— 攻方 LUK

| 項目 | 內容 |
|---|---|
| 啟用條件 | 技能**沒有** `gun` tag，且技能宣告 `canCrit = true` |
| 公式 | `30% × luk ÷ (luk + 128)` |
| 骰中結果 | 傷害 ×1.5 |

弓可以暴擊（`ranged` + `bow`），槍不行（`ranged` + `gun`）。255 LUK ≈ 19.95%。是否可暴擊由技能宣告（`canCrit`），法術也可以在技能定義中開啟暴擊。

### 碾壓（Crush）— Boss 限定

| 項目 | 內容 |
|---|---|
| 啟用條件 | 攻擊者有 `boss_source` tag（由副本場景標記） |
| 數值 | 預設 15%，各場景可自訂（15%～25%） |
| 骰中結果 | 傷害 ×2 |

碾壓排在表尾。防禦堆高時，普通命中歸零後碾壓第一個被擠出——這就是坦克玩法的本體：坦克透過堆高閃避/招架/格檔，把碾壓擠出攻擊表，大幅降低承受的爆發傷害。

### 命中（Hit）— 剩餘空間

| 項目 | 內容 |
|---|---|
| 公式 | `1 − (以上各列空間加總)` |
| 骰中結果 | 全額傷害 |

## Tag 啟用總表

| 列 | 需要的 tag | 排除的 tag | 備註 |
|---|---|---|---|
| 閃避 | — | `spell` | 法術必中 |
| 躲避 | — | `spell` | 法術必中 |
| 招架 | `melee` | — | 只有近戰可被招架 |
| 格檔 | — | — | 盾牌擋一切 |
| 暴擊 | — | `gun` | 槍不可暴擊；需技能宣告 `canCrit` |
| 碾壓 | `boss_source`（攻擊者） | — | Boss 限定 |
| 命中 | — | — | 剩餘空間 |

## 各技能類型的攻擊表組成

下表顯示各類型技能進攻擊表時，哪些列是啟用的。「—」表示該列跳過（寬度 0）。

| 列 | 近戰攻擊 | 弓攻擊 | 槍攻擊 | 傷害法術 |
|---|---|---|---|---|
| 閃避 | ✓ | ✓ | ✓ | — |
| 躲避 | ✓ | ✓ | ✓ | — |
| 招架 | ✓ | — | — | — |
| 格檔 | ✓ | ✓ | ✓ | ✓ |
| 暴擊 | 由技能宣告 | 由技能宣告 | — | 由技能宣告 |
| 碾壓 | Boss 限定 | Boss 限定 | Boss 限定 | Boss 限定 |
| 命中 | ✓ | ✓ | ✓ | ✓ |

槍攻擊的攻擊表最精簡（只有閃避、躲避、格檔、命中），對應「子彈撥不開、也不暴擊」的設計意圖。法術則是另一個極端：跳過閃避和躲避（必中），但保留格檔（盾牌連火球都擋得住）。

## 冰凍／暈眩狀態下的攻擊表

守方處於冰凍或暈眩時，以下列被停用：

| 列 | 正常 | 冰凍／暈眩 |
|---|---|---|
| 閃避 | ✓ | — |
| 躲避 | ✓ | ✓ |
| 招架 | ✓ | — |
| 格檔 | ✓ | — |
| 暴擊 | ✓ | ✓ |
| 碾壓 | ✓ | ✓ |
| 命中 | ✓ | ✓ |

躲避（幸運）仍在——因為躲避代表的是不可壓縮的「氣運」，不受身體狀態影響。這使得即便是被控制住的目標，也有微小的機率完全免傷。
