# Layer 1 — Primitives（原始公式層）

本文件收錄所有數學公式與基礎運算。這些是四層架構（Primitives → Pipeline → Rules → Content）的最底層，**調數值時永遠不動這一層**。

---

## 飽和曲線

全遊戲通用的收斂函數：

```
f(value) = value ÷ (value + 128)
```

---

## 生命與精神

```
maxHp = vit × 10
maxMp = wil × 5
```

無基礎值。起始屬性 = 10 → HP 100、MP 50。

---

## 攻速

攻擊間隔 = 武器基礎間隔 ÷ (1 + 加速)

```
加速 = 60% × agi ÷ (agi + 128)
```

255 AGI ≈ +40% 攻速。所有武器等比受益。槍械宣告 `agiApplies: false` 以忽略此項。

含 buff 的完整公式：

```
實際間隔 = 武器基礎間隔 ÷ 敏捷加速 ÷ max(0.05, 攻速效果倍率)
```

攻速效果倍率來自 buff/debuff 修飾系統（加速／減速／冰緩）。下限 0.05 防止除以零。

---

## 平衡擲骰（Mabinogi 式）

武器具有平衡值（0\~0.8）。傷害擲骰使用高斯分佈，中心點為 `min + range × balance`。

DEX 透過飽和曲線放大平衡：

```
放大率 = 60% × dex ÷ (dex + 128)
有效平衡 = min(0.8, 武器平衡 × (1 + 放大率))
```

64 DEX → +20%、128 DEX → +30%、255 DEX → +40%。

武器／技能宣告是否套用（`dexAmp`）。槍械不使用。

標準差 = range × 0.2。擲骰結果夾限於 \[min, max\]。

---

## 閃避（守方 AGI）

```
閃避空間 = (40% × agi ÷ (agi + 128)) × (1 − 50% × dex ÷ (dex + 128))
```

攻方 DEX 壓制守方閃避，但壓制上限 50%。

---

## 躲避（守方 LUK）

```
躲避空間 = 12% × luk ÷ (luk + 128)
```

不可壓制（不可壓縮區間）。

---

## 暴擊（攻方 LUK）

```
暴擊空間 = 30% × luk ÷ (luk + 128)
```

遠程武器不可暴擊（由 Rules 層的標籤決定，非本層職責）。

---

## Debuff 持續時間折減（守方 WIL）

```
實際持續 = 基礎持續 × (1 − 70% × wil ÷ (wil + 128))
```

255 WIL → −46.6%。趨近但永遠不達 −70%。

---

## 數值修飾統一規則

遊戲中所有數值（護甲、減傷率、攻速、格擋率、暴擊率……）皆遵守同一規則：

```
實際值 = (基準值 + 固定值效果加總) × 比例效果連乘
最低 0
```

- 固定值效果：加總（如 −8 與 −5 = −13）
- 比例效果：連乘（如 −30% 與 −20% = ×0.7 × 0.8 = ×0.56）
- 乘法疊加永遠不歸零；收斂行為如同飽和曲線
- 裝備詞綴在組裝時修改裝備自身數值（烘焙進去）。其他來源（buff、debuff、命中效果）在戰鬥時走此公式。

---

## 詠唱速度

```
詠唱時間 = 技能基礎詠唱 × 法杖倍率 ÷ max(0.05, 詠唱速度效果倍率)
```

法杖的 `castTimeMult`（如 0.85 = −15%）在組裝時烘焙。詠唱速度效果倍率來自 buff/debuff，下限 0.05。

---

## 屬性升級定價

每級費用依目標值所在階級而定：

| 區間（階級） | 每級費用 | 該區間花費 | 累計（從 10 起） |
|---|---|---|---|
| 11\~50（D） | 100 | 4,000 | 4,000 |
| 51\~100（C） | 300 | 15,000 | 19,000 |
| 101\~150（B） | 1,000 | 50,000 | 69,000 |
| 151\~200（A） | 3,000 | 150,000 | 219,000 |
| 201\~255（S） | 10,000 | 550,000 | 769,000 |

單屬性練滿 = 769,000。六屬性全滿 = 4,614,000。

## 敵人屬性預算

```
budget = (40 + 16 × floor) × (boss ? 1.4 : 1)
each_attr = 10 + round(budget × weight ÷ total_weights)
```

夾限於 0\~255。

---

## 敵人武器生成

```
min_damage = round((3 + 1.6 × floor) × damageMult × (boss ? 1.15 : 1))
max_damage = round((6 + 2.6 × floor) × damageMult × (boss ? 1.15 : 1))
armor = round(floor × 0.8) + (boss ? 4 : 0)
```

## 六主屬性總覽

範圍 0\~255，起始值 10。

| 屬性 | 縮寫 | 攻擊面 | 防禦面 |
|---|---|---|---|
| 力量 | STR | 近戰／弓傷害固定值直加 | — |
| 體質 | VIT | — | maxHp = VIT × 10 |
| 敏捷 | AGI | 攻速（飽和曲線） | 閃避（飽和曲線） |
| 靈巧 | DEX | 命中壓制（壓制閃避）、平衡放大 | — |
| 意志 | WIL | — | maxMp = WIL × 5、debuff 持續時間折減 |
| 幸運 | LUK | 暴擊（飽和曲線） | 躲避（飽和曲線） |
