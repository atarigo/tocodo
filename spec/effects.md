# Buff / Debuff 系統

## 效果三大類型

| 類型 | 行為 |
|---|---|
| 數值修飾 | 目標數值 ± 點數或比例，持續 y 秒。統一修飾規則：固定值加總、比例加總、最低 0 |
| 持續跳動 | 每秒結算生命增減，持續 y 秒。不同名可並存疊加（出血 + 流血 + 中毒…） |
| 狀態開關 | 特殊行為，每個單獨設計 |

## ⚠️ 待討論：疊加規則

原設計是「同名效果只存在一份，靠優先度覆蓋」。但這在即時戰鬥多敵人場景下有問題：被狼群圍毆，每隻狼的出血應該都能掛上。

### 需要決定的問題

1. **來源不同時是否疊加？** — 被三隻狼咬，三個出血各自獨立 tick？還是傷害加總為一個效果？
2. **同來源重複施放？** — 同一隻狼再咬一次，是刷新持續時間？還是疊加第二層？
3. **數值修飾型怎麼疊？** — 兩個不同來源的破甲效果，護甲 −8 + −8 = −16？
4. **疊加上限？** — 是否有最大疊加層數（防止無限疊加爆數值）？
5. **優先度的角色？** — 優先度是否只用於「同來源同名覆蓋」的判定，不影響不同來源的疊加？

### 暫定方向（待確認）

```
效果實例 = (效果名, 來源 ID)
- 不同來源：各自獨立存在，同時生效
- 同來源重複施放：看 stackRule（refresh = 刷新時間 / stack = 疊加層數 / replace = 取代）
- 可能需要每效果的最大疊加上限
```

---

以下為已定案部分（疊加規則確認後可能微調）：

## 通用規則

- 基本單位是**秒**
- 所有 debuff 的持續時間受意志影響：滿點意志 −70%
- 毒系（中毒、劇毒）：體質影響「附加成功率」，滿體質成功率 ×0.7；傷害不受體質影響

## 優先度（五階制）

效果的等階與技能/裝備一致（D/C/B/A/S）。高等階效果可以覆蓋低等階的同名效果。

具體的優先度數值（待疊加規則確認後定案）。

## 效果名錄（已定案，邊做邊加）

|---|---|---|---|---|
| 破甲 | 護甲值總和 | 點 | debuff (−) | |
| 佑甲 | 護甲值總和 | 點 | buff (+) | |
| 蝕甲 | 減傷率 | 比例 | debuff (−) | |
| 耀甲 | 減傷率 | 比例 | buff (+) | |
| 恍神 | 詠唱速度 | 比例 | debuff (−) | 詠唱變慢 |
| 專注 | 詠唱速度 | 比例 | buff (+) | 詠唱變快 |

| 名稱 | 單位 | 方向 | 毒系 | 備註 |
|---|---|---|---|---|
| 出血 | 點 | debuff (−) | 否 | |
| 流血 | 比例 | debuff (−) | 否 | |
| 中毒 | 點 | debuff (−) | 是 | 附加時吃體質成功率折減 |
| 劇毒 | 比例 | debuff (−) | 是 | 附加時吃體質成功率折減 |
| 燃燒 | 點 | debuff (−) | 否 | 火系；比例版名稱待定 |
| 恢復 | 點 | buff (+) | 否 | |
| 治療 | 比例 | buff (+) | 否 | |

### 狀態開關型

| 名稱 | 行為 |
|---|---|
| 冰凍 | 行動停止；累積受到最大生命 20% 傷害破冰；期間不能閃避、招架、格檔；附加時中斷詠唱 |
| 暈眩 | 同冰凍 |
| 沉默 | 無法使用任何技能；普攻不受影響 |

## 效果附加與破防

- 攻擊**未破防**時：附加效果不發動
- 例外：技能可宣告 `effectsIgnoreBreak: true`
- **格檔**可阻止「單體鎖定」效果，但不阻止範圍效果與暈眩

## 冰凍／暈眩的破除

破除池：累積受到最大生命 20% 的傷害即解除。包含普攻和持續跳動傷害。
