# Buff / Debuff 系統

## 效果三大類型

| 類型 | 行為 |
|---|---|
| 數值修飾 | 目標數值 ± 點數或比例，持續 y 秒。固定值加總、比例連乘、最低 0 |
| 持續跳動 | 每秒結算生命增減，持續 y 秒。不同名可並存疊加（出血 + 流血 + 中毒…） |
| 狀態開關 | 特殊行為，每個單獨設計 |

## 疊加規則（已定案）

### 效果實例識別

每個效果實例用（效果名、來源、等階）識別。

### 不同來源

各自獨立共存，無上限。

### 同來源同名同階

疊加到上限，滿了刷新時間。疊加上限由技能定義，0 = 只刷新。

### 同來源同名不同階

各自獨立共存。D 階出血和 C 階出血從同一來源可以同時存在，各自管各自的疊加和時間。

### 數值修飾的合算

- 固定值效果：全部加總（例：−8 和 −5 = −13）
- 比例效果：連乘（例：−30% 和 −20% = ×0.7 × 0.8 = ×0.56）
- 連乘永遠不會歸零
- 所有減屬性、減數值的 debuff 合計最低到 0

## 通用規則

- 基本單位是**秒**
- 所有 debuff 的持續時間受意志影響（飽和曲線，上限接近 −70%）

### 狀態開關型

| 名稱 | 行為 |
|---|---|
| 冰凍 | 行動停止；累積受到最大生命 20% 傷害破冰；期間不能閃避、招架、格檔；附加時中斷詠唱 |
| 暈眩 | 同冰凍 |
| 沉默 | 無法使用任何技能；普攻不受影響 |

## 效果附加與破防

- 攻擊**未破防**時：附加效果不發動
- 例外：技能可宣告 effectsIgnoreBreak
- **格檔**可阻止「單體鎖定」效果，但不阻止範圍效果與暈眩

## 冰凍／暈眩的破除

破除池：累積受到最大生命 20% 的傷害即解除。包含普攻和持續跳動傷害。
