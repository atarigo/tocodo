# 效果規則

Layer 3 — Rules。本文件定義效果（buff/debuff）的行為規則：疊加、持續、觸發、結算。效果的具體定義（名稱、數值、等階）放在 `content/effects.yaml`；本文件只描述所有效果共用的規則。

---

## 效果三大類型

| 類型 | 代號 | 行為 |
|---|---|---|
| 數值修飾 | Modifier | 目標數值 +/- 點數或比例，持續 y 秒。固定值加總、比例連乘、最低 0 |
| 持續跳動 | DoT / HoT | 每秒結算生命增減，持續 y 秒。不同名可並存疊加 |
| 狀態開關 | Toggle | 特殊行為，每個單獨設計（見下方「狀態開關型特殊規則」） |

---

## 效果實例識別

每個效果實例以三元組識別：

```
(效果名, 來源, 等階)
```

三元組決定疊加、刷新、獨立共存的判定。

---

## 疊加規則

### 不同來源

各自獨立共存，無上限。

### 同來源同名同階

疊加到上限，滿了刷新時間。疊加上限由技能定義（`maxStacks` 欄位），`0` 表示只刷新不疊加。

### 同來源同名不同階

各自獨立共存。例：D 階出血和 C 階出血從同一來源可以同時存在，各自管各自的疊加數和持續時間。

---

## 數值修飾的合算

所有生效中的數值修飾效果，對同一目標值按以下規則合算：

```
實際值 = (基準值 + 固定值效果加總) × 比例效果連乘
最低 0
```

規則細節：

- 固定值效果：全部加總。例：-8 和 -5 = -13。
- 比例效果：連乘。例：-30% 和 -20% = x0.7 x 0.8 = x0.56。
- 連乘永遠不會歸零，堆越多效果越差（與飽和曲線同理）。
- 所有減屬性、減數值的 debuff 合計最低到 0。

統一公式見 `01-primitives.md`「數值修飾統一規則」。

---

## 持續時間

- 基本單位是**秒**。
- 所有 debuff 的持續時間受意志折減（見 `01-primitives.md`「Debuff 持續時間折減」）。
- Buff 持續時間不受意志影響。

意志折減公式：

```
實際持續 = 基礎持續 × (1 − 70% × wil ÷ (wil + 128))
```

## 效果觸發條件

### 命中判定

有命中（未被閃避/躲避）→ 效果進入生效判定。生效判定 = 技能定義的機率（`chance` 欄位）。

### 破防與效果的關係

攻擊**未破防**時，附加效果**不發動**。

例外：技能可宣告 `effectsIgnoreBreak: true`，即使未破防也觸發效果。此旗標在 `content/skills.yaml` 中逐技能宣告。

### 格檔與效果的關係

**格檔**可阻止「單體鎖定」效果（single-target debuffs），但**不能**阻止範圍效果和暈眩。

效果屬於「單體鎖定」或「範圍/暈眩」由效果定義決定（`content/effects.yaml`）。

## 狀態開關型特殊規則

### 冰凍 (Freeze)

- 行動停止（不能攻擊、不能施法）。
- 累積受到最大生命 20% 傷害即破冰（包含普攻和 DoT 傷害）。
- 期間不能閃避、招架、格檔；躲避（幸運）仍在。
- 附加時中斷詠唱。

### 暈眩 (Stun)

行為同冰凍。

### 沉默 (Silence)

- 無法使用任何技能。
- 普攻不受影響。

### 冰凍/暈眩對攻擊表的影響

當防禦方處於冰凍或暈眩狀態：

| 攻擊表段 | 狀態 |
|---|---|
| 閃避 (Dodge) | 禁用 |
| 躲避 (Evasion) | 仍然生效（基於幸運，始終存在） |
| 招架 (Parry) | 禁用 |
| 格檔 (Block) | 禁用 |

## 可修飾目標清單

效果可修飾的戰鬥數值（隨管線擴充）：

| 目標 | 代號 | 備註 |
|---|---|---|
| 護甲值總和 | `armor` | 固定值修飾 |
| 減傷率 | `reductionRate` | 比例修飾 |
| 詠唱速度 | `castSpeed` | 比例修飾 |
| 攻速 | `attackSpeed` | 比例修飾 |

新目標可隨管線擴充加入。
