# 六主屬性

## 總則

範圍 **0〜255**（六邊形戰士的六軸），起始 **10**。沒有預設數值：所有基本狀態都由屬性或裝備提供，全部歸零就是什麼都沒有。

## 屬性定義

| 屬性 | 縮寫 | 主要影響（攻） | 主要影響（守） |
|---|---|---|---|
| 力量 | STR | 近戰／弓傷害固定值直加 | — |
| 體質 | VIT | — | 生命上限（×10）、毒系附加成功率折減 |
| 敏捷 | AGI | 攻速（依武器宣告） | 閃避 |
| 靈巧 | DEX | 命中壓制（壓制閃避）、平衡放大 | — |
| 意志 | WIL | — | 精神上限（×5）、debuff 持續時間縮減 |
| 幸運 | LUK | 暴擊（攻方） | 躲避（守方） |

## 衍生值公式（已定案）

### 生命與精神

沒有基礎值，全部由屬性提供。起始 10 → 生命 100、精神 50。

```
maxHp = vit × 10
maxMp = wil × 5
```

### 攻速（飽和曲線）

出手間隔 = 武器基礎間隔 ÷ (1 + 加速)

```
加速 = 60% × agi ÷ (agi + 128)
```

255 敏捷約 +40% 攻速。所有武器等比受益，武器個性不被屬性洗掉。槍類「射速只看武器」= 由武器宣告不吃敏捷（`agiApplies: false`）。

### 平衡（Mabinogi 式）

武器自帶平衡值（0〜0.8），傷害擲骰以「最小傷 + 範圍 × 平衡」為中心的高斯分佈，超出大小傷範圍夾回。

靈巧以乘法放大平衡值，走飽和曲線：

```
放大率 = 60% × dex ÷ (dex + 128)
有效平衡 = min(0.8, 武器平衡 × (1 + 放大率))
```

64 靈巧 +20%、128 靈巧 +30%、255 靈巧約 +40%。

是否吃平衡由武器／技能宣告（`dexAmp`）。槍類不吃。

鐘形標準差 = 範圍 × 0.2。

### Debuff 持續時間（意志抗性）

```
實際持續 = 基礎持續 × (1 − 0.7 × wil ÷ 255)
```

滿意志 −70%（線性）。

### 毒系附加成功率（體質折減）

```
實際成功率 = 基礎成功率 × (1 − 0.3 × vit ÷ 255)
```

滿體質成功率 ×0.7。傷害本身不受體質影響。
