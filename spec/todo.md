# 規格 vs 程式碼差異清單與 TODO

## 比對方法

逐一比對 `spec/` 下每份規格文件與 `src/` 下現行程式碼的差異。標記為：

- 🔴 **缺失**：規格定義了但程式碼完全沒有
- 🟡 **部分**：有實作但與規格不一致或不完整
- 🟢 **一致**：程式碼符合規格
