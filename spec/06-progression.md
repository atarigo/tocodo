# 進度與經濟系統

## 核心循環

城市 → 副本傳送門 → 同階級隨機副本（多場景推進）→ 通關結算 → 回到城市。

死亡不繼承任何東西——那是另一個人生。

## 角色狀態

```typescript
type EquipmentSlot =
  | 'head'      // 頭
  | 'neck'      // 頸
  | 'body'      // 甲
  | 'mainHand'  // 主手
  | 'offHand'   // 副手
  | 'ring1'     // 手飾 1
  | 'ring2'     // 手飾 2
  | 'waist'     // 腰
  | 'legs'      // 腿
  | 'feet';     // 腳

interface CharacterState {
  name: string;
  rank: Rank;                                // D/C/B/A/S
  rankProgress: number;                      // 同階通關次數（滿 15 升階）
  attrs: Attributes;                         // 六主屬性，0~255，起始 10
  rewardPoints: number;                      // 獎勵點（唯一貨幣），起始 0
  inventory: string[];                       // 物品 ID
  knownSkills: SkillInstance[];              // 已習得技能（含等階與等級）
  equipment: Record<EquipmentSlot, string | null>;  // 裝備（所有部位統一管理）
  skillSlots: string[];                      // 技能欄（最多 5 格）
}
```

所有裝備（武器、防具、原本的飾品）統一按部位管理，走同一套 provides 格式、同一套公式和計算管道。不存在「飾品」這個獨立分類——項鍊是頸部裝備、戒指是手飾、護目鏡是頭部裝備、靴子是腳部裝備。

## 五階制

所有內容以五階設計：**D / C / B / A / S**。

涵蓋：玩家階級、副本階級、武器階級、裝備階級、技能階級、道具階級、效果優先度。

### 升階

通關同階副本 **15 次**升階（暫定固定值，以後可調）。升階不可逆。

### 等階與等級

所有裝備和技能都有**等階**（D/C/B/A/S）和**等級**（1~11）兩個維度。

- 等級（1~11）：透過使用或精煉提升。每個物件自行定義各級效果。
- 等階升級：技能用升階捲軸；武器/裝備方式待定（特殊材料或副本獎勵）。
- 升階後等級重置為 1。
- 一個技能/武器/裝備 = 5 階 × 11 級 = 55 種狀態需設計。

## 經濟系統

### 獎勵點（唯一貨幣）

起始值 = 0。所有獎勵點都從副本獲得。死亡不繼承——那是另一個人生。

### 獎勵來源

所有獎勵在副本通關後統一結算：

- 場景通關獎勵點
- 擊殺獎勵點（每隻怪定義）
- optional 勝利條件的額外獎勵點
- 難度加成倍率
- 扣除：場景內消費（降難度、交易）

### 商店基準定價

基準定價與屬性升級花費對齊：

| 階級 | 基準定價 | 屬性區間 |
|---|---|---|
| D | 4,000 | 11~50（40級 × 100） |
| C | 15,000 | 51~100（50級 × 300） |
| B | 50,000 | 101~150（50級 × 1,000） |
| A | 150,000 | 151~200（50級 × 3,000） |
| S | 550,000 | 201~255（55級 × 10,000） |

### 商店

- 有 `price` 欄位的物品 → 一般商店販售
- 沒有 `price` → 只能副本取得

### 秘密商店（待實作）

- 需要秘密鑰匙道具
- 消費使用獨立的秘密點數
- 唯一能透過購買取得特殊道具的地方

## 起始配置

- 起始階級：D
- 起始屬性：全部 10
- 起始獎勵點：0（空身開局）
- 起始物品：無
- 技能欄上限：5 格
- 第一個副本（D 階）提供難度選項，讓空身玩家可以選擇降低難度通關

## 偉業系統（紀元全域效果）

有人在世界中達成隱藏條件時，全體玩家獲得對應效果。「前人種樹後人乘涼」只發生在世界層級，不在個人層級。

現階段用常數開關，上線後改由後端 API 提供。

```typescript
interface WorldEffects {
  攻擊聖火: number;   // 全體攻擊加成（0.1 = +10%，0 = 未觸發）
  守護壁壘: number;   // 全體防禦加成（護甲值倍率）
  遺產祝福: number;   // 獎勵點倍率（平時 1，觸發日 2）
}
```

## Entity 統一模型

所有可戰鬥的實體（主角、敵人、NPC）共用同一套資料結構：屬性、裝備、技能、道具。攻防計算只有一條管線，不因對象類型而分流。

裝備依取得方式分為兩類：

- 一般裝備：有 `price` 欄位，可透過掉落、購買等方式取得
- 天生裝備：無 `price` 欄位，不可取得、不可掉落（爪牙、毛皮等與生俱來的裝備）

兩類在資料格式和計算公式上完全一致，差別只在取得方式。任何 entity 都能使用任何一類裝備，不設限制——獸型 NPC 用爪牙，人型敵人拿劍，全由設定檔決定。

## 角色組裝（養成 → 戰鬥單位）

養成狀態 + 世界效果 = 戰鬥單位。裝備詞綴在組裝時烤死，戰鬥中的 buff/debuff 走效果系統（見 05-effect-rules.md）。

```
護甲 = round(裝備護甲加總 × (1 + 守護壁壘))
減傷率 = min(0.8, 裝備減傷率加總)
格檔率 = min(0.45, 盾牌格檔率)
招架率 = 武器招架率
增傷倍率 = 1 + 攻擊聖火
```
