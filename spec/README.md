# 世界（第一紀元）— 遊戲規格

穿梭副本、自由配裝的網頁 Roguelite。靈感來自《無盡武裝》：強迫晉級、不適者淘汰、前人種樹後人乘涼（世界層級）。

## 核心哲學

引擎只提供共用公式與結算管線，每個技能、每把武器各自宣告吃哪些屬性、怎麼吃。職業是從機制長出來的，不是設計出來的。

## 核心循環

城市 → 副本傳送門 → 同階級隨機副本（多場景推進）→ 通關結算 → 回到城市。

死亡不繼承任何東西——那是另一個人生。
