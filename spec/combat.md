# 戰鬥系統

## 設計原則

戰鬥是連續時間軸：攻速、詠唱、冷卻、buff/debuff 都以秒計，每個單位照自己的節奏出手。

**防守天生吃虧**：防禦相關的計算是「減少傷害」而不是「抵銷傷害」，不能造就靠屬性就無解的全防流。躲避是特例（投資極大、上限不到 12%）。反過來，純減傷投資（如敏捷的閃避）也不能被攻方屬性完全吃掉——壓制上限砍半。

## 技能四分類

所有技能分為兩軸四類：法術 vs 非法術、有傷害 vs 無傷害。

### 傷害法術（如火球術）

- **必中**：骰表移除閃避和躲避
- 可招架、格檔、暴擊、碾壓
- 傷害計算：招架/格檔可減傷，裝備若有抗性屬性也可減傷，但護甲的減數和減成不適用
- 效果必定進入生效判定（技能定義機率），debuff 受意志折減

### 非傷害法術（如詛咒術）

- **必中**，不骰表，無傷害計算
- 效果必定進入生效判定（技能定義機率），debuff 受意志折減

### 傷害非法術（如割裂）

- 完整骰表（閃避/躲避/招架/格檔/暴擊/碾壓）
- 傷害走完整公式（護甲減數、減成、折減）
- 有命中（未被閃避/躲避）就進入效果生效判定，生效與否看技能定義機率

### 非傷害非法術（如衝刺）

- **必中**，不骰表，無傷害計算
- 效果必定進入生效判定

### 規則總結

- 只有「傷害非法術」才有閃避和躲避，其餘都是必中
- 有命中，效果就進入生效判定
- 生效與否看技能定義的機率
- 所有 debuff 持續時間受意志折減

## 單骰攻擊表

### 骰表結構

傷害非法術使用完整表，傷害法術移除閃避和躲避。

每次攻擊先依攻守雙方數值「組表」，再擲一顆骰決定結果。雙邊數值的比較全部發生在組表時，擲骰本身不看任何屬性。

Bar 依固定優先序填入，空間不足從尾端截斷：普通命中先歸零 → 碾壓被擠出 → 最後才是暴擊。

| 段 | 公式／來源 | 結果 |
|---|---|---|
| 閃避 | (40% × agi ÷ (agi + 128)) × (1 − 50% × dex ÷ (dex + 128)) | 無傷、無效果（僅非法術） |
| 躲避 | 12% × luk ÷ (luk + 128)，不可被壓縮 | 無傷、無效果（僅非法術） |
| 招架 | 武器提供 5%〜25%（屬性不提供） | 傷害 ×0.7，擋不住效果 |
| 格檔 | 盾牌提供 30%〜45%（無盾 = 0） | 傷害 ×0.4，可擋單體鎖定效果 |
| 暴擊 | 30% × luk ÷ (luk + 128)（飽和曲線）；槍不可暴擊 | 傷害 ×1.5 |
| 碾壓 | 頭目普攻限定，統一預設 15%（各頭目可自訂） | 傷害 ×2 |
| 命中 | 剩餘空間 | 全額 |

### 冰凍／暈眩狀態下

不能閃避、招架、格檔；躲避（幸運）仍在。

## 傷害計算

### 非法術傷害（完整公式）

```
1. 基礎傷害 = 平衡擲骰 + 力量（若武器宣告吃力量）
2. 來襲傷害 = 基礎傷害 × 增傷倍率
   若暴擊：來襲傷害 ×= 1.5
   若碾壓：來襲傷害 ×= 2
3. 破防判定：
   來襲傷害 > 護甲值總和 → 破防，進入後續減傷
   來襲傷害 > 護甲值總和 ÷ 3 → 未破防，強制傷害 1
   來襲傷害 ≤ 護甲值總和 ÷ 3 → 完全擋下，傷害 0
4. 減算：來襲傷害 − 護甲值總和
5. 減成：× (1 − 減傷率)
6. 折減：
   若招架：× 0.7（減免 30%）
   若格檔：× 0.4（減免 60%）
7. 最終傷害 = max(1, round(結果))
```

### 法術傷害

```
1. 基礎傷害 = 技能定義（base + 屬性 scaling）
2. 來襲傷害 = 基礎傷害 × 增傷倍率
   若暴擊：來襲傷害 ×= 1.5
   若碾壓：來襲傷害 ×= 2
3. 不走護甲減數和減成
4. 折減：
   若招架：× 0.7
   若格檔：× 0.4
5. 裝備若有抗性屬性，可額外減傷（待定義）
6. 最終傷害 = max(1, round(結果))
```

### 穿透與真傷

- **穿透**：無視護甲值總和（必定破防），仍吃減傷率與招架/格檔折減
- **真傷**：不走傷害計算，打技能宣告的固定值，不計增傷、不計任何防禦與折減

## 效果發動

- 有命中（未被閃避/躲避）→ 效果進入生效判定
- 生效判定 = 技能定義的機率
- 破防與否不影響效果發動
- **格檔**可阻止「單體鎖定」效果，但不阻止範圍效果與暈眩

## 招架與格檔

率與效果都由技能或裝備提供，屬性不提供；皆可被 buff/debuff 增減。

- **招架**：一般武器都會給（5%〜25%）。減免傷害 30%。無法阻止效果發動。
- **格檔**：只有盾牌會給（30%〜45%）。固定減免傷害 60%。可阻止「單體鎖定」效果發動，但無法阻止範圍效果與暈眩。

## 碾壓

頭目普攻限定。統一預設 15%，各頭目可自訂（15%〜25%）。傷害 ×2。碾壓排在攻擊表最末，防禦堆高時在普通命中歸零後第一個被擠出——坦克玩法的本體。

## 數值修飾統一規則（已定案）

裝備詞綴先改裝備自己的值，組裝時烤死（例：手套 +25% 護甲 → 10 變 12.5）。

其他來源（buff、debuff、攻擊當下特效）：

```
實際值 = (基準值 + 固定值效果加總) × 比例效果連乘
最低 0
```

- 固定值效果：加總（例：−8 和 −5 = −13）
- 比例效果：連乘（例：−30% 和 −20% = ×0.7 × 0.8 = ×0.56）
- 連乘永遠不會歸零，堆越多效果越差，跟飽和曲線同理

全遊戲所有數值（護甲值、減傷率、攻速、招架率、暴擊率…）同一條規則。

攻擊當下的特效不是 debuff，可與 debuff 疊加。

## 攻速效果倍率

```
實際間隔 = 武器基礎間隔 ÷ 敏捷加速 ÷ max(0.05, 攻速效果倍率)
```

攻速效果倍率由 buff/debuff 的數值修飾系統提供（加速/減速/冰緩），下限 0.05 避免除以零。

## 詠唱速度

```
詠唱時間 = 技能基礎詠唱 × 法杖倍率 ÷ max(0.05, 詠唱速度效果倍率)
```

法杖的 castTimeMult（如 0.85 = −15%）在組裝時烤入。
