# 戰鬥系統

## 設計原則

戰鬥是連續時間軸：攻速、詠唱、冷卻、buff/debuff 都以秒計，每個單位照自己的節奏出手。

**防守天生吃虧**：防禦相關的計算是「減少傷害」而不是「抵銷傷害」，不能造就靠屬性就無解的全防流。躲避是特例（投資極大、上限不到 12%）。反過來，純減傷投資（如敏捷的閃避）也不能被攻方屬性完全吃掉——壓制上限砍半。

## 攻擊判定：單骰攻擊表（兩階段）

### 第一階段：骰表

每次攻擊先依攻守雙方數值「組表」，再擲一顆骰決定結果。雙邊數值的比較全部發生在組表時，擲骰本身不看任何屬性。

Bar 依固定優先序填入，空間不足從尾端截斷：普通命中先歸零 → 碾壓被擠出 → 最後才是暴擊。

| 段 | 公式／來源 | 結果 |
|---|---|---|
| 閃避 | (40% × 守方 agi ÷ 255) × (1 − 0.5 × 攻方 dex ÷ 255) | 無傷、無效果 |
| 躲避 | 12% × 守方 luk ÷ (luk + 128)，不可被壓縮 | 無傷、無效果 |
| 招架 | 武器提供 5%〜25%（屬性不提供） | 傷害 ×0.7，擋不住效果 |
| 格檔 | 盾牌提供 30%〜45%（無盾 = 0） | 傷害 ×0.4，可擋單體鎖定效果 |
| 暴擊 | 30% × 攻方 luk ÷ 255（線性）；槍不可暴擊 | 傷害 ×1.5 |
| 碾壓 | 頭目普攻限定，統一預設 15%（各頭目可自訂） | 傷害 ×2 |
| 命中 | 剩餘空間 | 全額 |

#### 閃避公式（飽和曲線）

```
閃避 = (40% × agi ÷ (agi + 128)) × (1 − 50% × dex ÷ (dex + 128))
```

敏捷 255 vs 靈巧 0 → 26.6%；敏捷 255 vs 靈巧 255 → 17.8%。上限接近但不到 40%。

#### 躲避公式

```
evadeWidth = 0.12 × defender.luk ÷ (luk + 128)
```

飽和曲線：幸運 128 → 6%、255 → 8%。不可被任何機制壓縮——命中永遠堆不滿的原因。

#### 暴擊公式（飽和曲線）

```
暴擊 = 30% × luk ÷ (luk + 128)
```

幸運 255 → 20%。上限接近但不到 30%。暴擊在 bar 尾端、會被守方防禦段擠壓，有天然反制。

#### 宣告機制

每次攻擊宣告自己適用哪些段：

- 近戰普攻：全適用
- 射擊（projectile）：不可被招架（`canBeParried: false`）
- 碾壓：只在頭目普攻（`attackerCrushRate > 0`）
- 冰凍／暈眩狀態下（`defenderIncapacitated`）：不能閃避、招架、格檔；躲避（幸運）仍在

### 第二階段：傷害計算

```
1. 基礎傷害 = 平衡擲骰 + 力量（若武器宣告吃力量）
2. 來襲傷害 = 基礎傷害 × 增傷倍率
   若暴擊：來襲傷害 ×= 1.5
   若碾壓：來襲傷害 ×= 2
3. 破防判定：來襲傷害 > 護甲值總和？
   未破防 → 傷害 = 1，該次攻擊特效不發動（例外由技能宣告 effectsIgnoreBreak）
4. 減算：來襲傷害 − 護甲值總和
5. 減成：× (1 − 減傷率)
6. 折減：
   若招架：× 0.7（減免 30%）
   若格檔：× 0.4（減免 60%）
7. 最終傷害 = max(1, round(結果))
```

增傷先乘的理由：暴擊要能幫助破防，混進減傷率會讓暴擊流對高甲目標報廢。

### 穿透與真傷

- **穿透**（`pierce`）：無視護甲值總和（必定破防），仍吃減傷率與招架/格檔折減
- **真傷**（`trueDamage`）：不走第二階段，骰到什麼都算命中，打技能宣告的固定值，不計增傷、不計任何防禦與折減

### 招架與格檔（已定案）

率與效果都由技能或裝備提供，屬性不提供；皆可被法術 buff/debuff 增減。

- **招架**：一般武器都會給（5%〜25%）。減免傷害 30%。無法阻止效果發動。
- **格檔**：只有盾牌會給（30%〜45%）。固定減免傷害 60%。可阻止「單體鎖定」效果發動（如冰箭的緩速、近戰致盲），但無法阻止範圍效果與暈眩。

### 碾壓

頭目普攻限定。統一預設 15%，各頭目可自訂（15%〜25%）。傷害 ×2。碾壓排在攻擊表最末，防禦堆高時在普通命中歸零後第一個被擠出——坦克玩法的本體。

## 數值修飾統一規則（已定案）

裝備詞綴先改裝備自己的值，組裝時烤死（例：手套 +25% 護甲 → 10 變 12.5）。

其他來源（buff、debuff、攻擊當下特效）：

```
實際值 = (基準值 + 固定值效果加總) × (1 + 比例效果加總)
最低 0
```

全遊戲所有數值（護甲值、減傷率、攻速、招架率、暴擊率…）同一條規則。

攻擊當下的特效不是 debuff，可與 debuff 疊加。

## 戰鬥時間上限

超過 90 秒視為玩家落敗。

## 攻速效果倍率

```
實際間隔 = 武器基礎間隔 ÷ 敏捷加速 ÷ max(0.05, 攻速效果倍率)
```

攻速效果倍率由 buff/debuff 的數值修飾系統提供（加速/減速/冰緩），下限 0.05 避免除以零。

## 詠唱速度

```
詠唱時間 = 技能基礎詠唱 × 法杖倍率 ÷ max(0.05, 詠唱速度效果倍率)
```

法杖的 `castTimeMult`（如 0.85 = −15%）在組裝時烤入。
