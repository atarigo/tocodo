# 世界（第一紀元）

穿梭副本、自由配裝的網頁 Roguelite。靈感來自《無盡武裝》的世界觀：強迫晉級、不適者淘汰、前人種樹後人乘涼（世界層級）。

完整規則見 [docs/design.md](docs/design.md)。

## 怎麼玩

```sh
make install
make game     # 瀏覽器開 http://localhost:5173
```

畫面是左中右三欄：左欄角色屬性／裝備／商店，中欄戰鬥舞台（自動戰鬥回放），右欄戰報（往上捲可完整回顧）。

核心循環：**用貨幣買屬性、裝備、技能（只能在副本之間）→ 進副本自動戰鬥 → 撤退結算或死亡淘汰 → 死亡不繼承任何東西，下一段人生重新開始。**

### 規則速覽

- **六主屬性**：力量、體質、敏捷、靈巧、意志、幸運。每個技能、武器各自宣告吃哪些屬性——職業是從機制長出來的，不是設計出來的。
- **戰鬥是連續時間軸**：攻速、詠唱、冷卻、buff/debuff 都以秒計，每個單位照自己的節奏出手。
- **單一貨幣**：升屬性、買東西都用它，副本給貨幣與掉落。**死亡不繼承**——那是另一個人生了。
- **五階制**：D／C／B／A／S。效果覆蓋看優先度、商店價格由階級推導；沒有標價的東西商店不賣，只能副本取得。
- **強迫晉級**：起始層數 = 本人最高層 − 2，不能回頭刷低層；血量跨層延續、層間只回 25%。每 5 層有頭目。
- **偉業（世界效果）**：有人達成隱藏條件，全世界受益。現階段是 `src/data/worldEffects.ts` 的常數開關，上線後改由後端提供。

## 開發

```sh
make check    # 型別檢查（tsc + svelte-check）+ 測試
make sim      # 平衡模擬：四種流派打 1〜15 層的勝率表
make build    # 正式建置
```

### 架構

```
src/
  core/      遊戲核心：純函式，不依賴任何環境
    types.ts      資料模型（六屬性、武器、技能、狀態、五階）
    attributes.ts 衍生值公式、發揮度擲骰
    combat.ts     連續時間軸自動戰鬥模擬器（輸出帶時間戳的事件流）
    effects.ts    buff/debuff：優先度覆蓋、抵抗、持續傷害
    character.ts  養成狀態 + 世界效果 → 戰鬥單位
    dungeon.ts    敵人原型與難度曲線、強迫晉級
    loot.ts       掉落與貨幣報酬
  data/      內容資料：武器、裝備、技能、狀態、世界效果（加內容 = 加資料）
  game/      經濟規則（屬性價格、商店、層數報酬）
  state/     存檔資料模型（網頁版存 localStorage）
  web/       Svelte 介面：左（角色面板）中（戰鬥舞台）右（戰報）
             playback.ts 是純 JS 的回放控制器，之後換 PixiJS 也接這裡
  sim.ts     平衡模擬工具（終端機）
```

戰鬥模擬器跑完整場戰鬥後輸出事件流，網頁照時間軸回放——畫面只是播放器，邏輯與表現完全分離。
