# 血腥都市（第一紀元）

穿梭副本、自由配裝的純文字 Roguelite。靈感來自《無盡武裝》的世界觀：強迫晉級、不適者淘汰、前人種樹後人乘涼。

## 怎麼玩

```sh
pnpm install
pnpm game
```

核心循環：**配裝／配技能／分配屬性點 →（鎖定 build）進入副本自動戰鬥 → 撤退結算或死亡淘汰 → 遺產留給下一位角色**。

### 規則

- **副本**：一層一戰，自動戰鬥。每攻克一層獲得 2 屬性點與掉落機會，層間只回復 25% 生命——血量會延續，貪層是會死的。每 5 層有頭目。
- **強迫晉級**：起始層數 = 歷史最高層 − 2（最低第 1 層），不能回頭刷低層。
- **淘汰**：死亡即失去角色（屬性點、配置全失），但**倉庫裝備、已習得技能、遺產點數永久保留**。
- **遺產**：每次副本結算「攻克層數 × 遺產祝福倍率」的遺產點數，可在遺產商店購買對所有後續角色生效的永久強化。
- **Build**：裝備三槽（武器／防具／飾品）＋ 技能四格。技能依格子順序優先施放（冷卻中則往後找，全冷卻則普攻）。加成綁在「標籤」上（物理／火焰／冰霜／血祭），例如烈焰之刃讓所有火焰技能傷害 +30%。

### 偉業（世界效果）

設計目標：有人在世界中達成隱藏條件（獻祭、使用特殊道具……），全體玩家獲得全域效果。上線後由後端提供；現階段是 `src/data/worldEffects.ts` 裡的常數開關，改數值即可模擬「有人觸發了偉業」的世界。

## 開發

```sh
pnpm typecheck   # 型別檢查
pnpm test        # 戰鬥公式與規則測試
pnpm sim         # 平衡模擬：典型成長曲線打 1〜15 層的勝率表
```

### 架構

刻意分成兩層，未來上網頁 UI 時遊戲核心不需要改動：

```
src/
  core/      遊戲核心：純函式，不依賴任何執行環境
    types.ts      資料模型（屬性、技能、裝備、標籤）
    combat.ts     自動戰鬥模擬器
    character.ts  養成狀態 + 世界效果 → 戰鬥單位
    dungeon.ts    敵人生成與難度曲線、強迫晉級規則
    loot.ts       掉落結算
    rng.ts        可植入種子的偽隨機（測試與模擬可重現）
  data/      內容資料：技能、裝備、世界效果（加內容 = 加資料）
  state/     存檔結構與讀寫（目前是本地 save.json）
  cli.ts     介面層：終端機選單（之後換成網頁畫面）
  sim.ts     平衡模擬工具
```

### 平衡現況

`pnpm sim` 顯示：1〜14 層對典型 build 可穩定通過但血量逐層吃緊（第 10 層頭目勝後僅剩約 15% 生命），第 15 層頭目是目前裝備池的天花板，需要累積遺產強化才推得過去——這是刻意的：淘汰 → 遺產 → 後人更強。
